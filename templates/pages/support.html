Getting connected

Which devices can run GlanceVNC?

GlanceVNC requires iOS 18 or later on iPhone, or iPadOS 18 or later on iPad. Connect to a Mac, Windows PC, Linux computer or Raspberry Pi running a compatible VNC or RDP server, or Mac Screen Sharing, that your device can reach.

How do I connect to a Mac?

Enable Screen Sharing on the Mac and the option allowing VNC viewers to control the screen with a password. Add the Mac host name or IP address, leave Operating System set to Mac, select VNC password and enter that VNC password. A Mac account password is not interchangeable with the separately configured VNC password. Standard Mac Screen Sharing does not offer the certificate-backed VeNCrypt mode used by the optional strict VNC security setting.

How do I add a VNC connection?

Open Saved Connections and tap Add Connection. Choose VNC, enter the host or IP address and port (usually 5900), then choose the Operating System and sign-in method. Mac is the default Operating System; this choice also sets remote keyboard shortcuts. Set display, pointer and VNC colour preferences for this connection before saving. A vnc:// prefix is accepted.

How do I add an RDP connection?

Open Saved Connections and tap Add Connection. Choose RDP, enter the host or IP address and port (3389 by default), and add the remote account username and password. Choose Windows or Linux under Operating System so hardware keyboard shortcuts use Control. The remote desktop needs a reachable RDP server. Ordinary usernames, user@domain names and DOMAIN\username are supported.

How does nearby discovery work?

GlanceVNC finds Bonjour VNC services advertised as _rfb._tcp. on your local network. Choose a discovered desktop to connect immediately after entering its details, or save it for later. Allow Local Network access when prompted. If discovery is unavailable, check the app’s Local Network permission in system Settings, or enter the host and port manually.

Controls & display

How do I choose Touch or Trackpad mode?

During a connection, open the expanded toolbar, choose Settings, then Pointer mode. Touch positions the pointer where you tap and keeps the zoomed view still. Trackpad moves the pointer relative to your finger and follows it when zoomed in. To set a connection’s starting mode, edit that connection’s Session Preferences. Switching modes during a session keeps your zoom level.

What touch gestures are available?

Tap for a left click, double-tap for a double-click, use a two-finger tap for a right click, hold and drag to move items, and use two fingers to scroll the remote computer. Pinch zoom is always available and changes your local view, not the computer’s screen resolution. In Trackpad mode, zoom centres on the pointer and the view follows it until the desktop edge; in Touch mode, pinch around an area and tap the enlarged content directly. For gesture instructions during a session, open Settings and select How to control your computer.

How does Apple Pencil work?

On iPad, Apple Pencil works automatically as a direct remote pointer in Touch or Trackpad mode. Tap with the tip for a left click; keep it down and move to drag or draw. Hover moves the cursor without clicking on supported iPads. Finger navigation resumes when the Pencil lifts. Pressure, tilt, squeeze and Pencil double-tap actions are not part of this pointer feature.

How do I send keyboard input?

Tap the keyboard button during a session to show the on-screen keyboard; it hides when a hardware keyboard is attached. Hardware keyboards work immediately. Command+C/X/A/Z and Command+Shift+Z send copy, cut, select all, undo and redo. Command+V transfers device clipboard text and pastes it remotely; Command+Shift+V pastes the existing remote clipboard. The connection’s Operating System choice sends remote Command for Mac and Control for Windows or Linux.

Does clipboard text work?

Version 1.3 supports plain-text clipboard exchange in compatible VNC, Mac Screen Sharing and RDP sessions. Tap the upward chevron to show the controls. Copy text on the remote computer, then tap Copy from remote to copy it to your device. Paste to remote sends text from your device clipboard to the remote clipboard; approve the iOS paste prompt if asked, then use the remote app’s Paste command to insert it. Images and files are not supported.

How do I choose colour depth?

In Add or Edit Connection, open Session Preferences and choose 16-bit or 24-bit VNC colour depth. The choice is saved for that connection on this device and applies on the next connection. RDP uses its own colour handling.

Can GlanceVNC resize the remote desktop?

GlanceVNC requests a landscape desktop size matching the session area when the remote server supports resizing. Mac Screen Sharing retains the Mac display resolution. Choose Fit whole desktop to see the whole screen or Fill screen to crop the edges without stretching. Pinch zoom enlarges only the local view.

Can I customise the home screen?

Open Settings and choose Choose Background to pick a photo; GlanceVNC stores a resized copy on this device. Use Default Background removes it. Saved connection cards can show locally cached desktop thumbnails; turn off Show Connection Thumbnails in Settings to use placeholders instead.

How do I close a remote session?

Tap the upward chevron to show the session controls, open Settings, and choose Close Connection. Confirm when prompted.

Security & compatibility

What sign-in method should I choose?

For VNC, use Automatic for most servers. Without strict certificate security, it can select legacy Mac login when offered or standard VNC password authentication. With Require certificate security enabled on a compatible VeNCrypt server, Automatic selects a supported X.509 mode. Choose VNC password when the server requires its VNC viewer password. Mac login requires a compatible legacy Apple Remote Desktop server and cannot be combined with strict VNC security.

How do RDP certificate approvals work?

RDP uses TLS. If the server certificate needs approval, review and trust it only after checking that it belongs to your computer. Approval is remembered; a changed certificate requires a new review. You can instead enable Require certificate security in Add or Edit Connection to enforce system trust, an imported certificate or a SHA-256 fingerprint. Strict verification failures block the connection without an approval override. To reset a legacy approval, edit the saved RDP connection and choose Forget Trusted Certificate.

How does certificate security work?

In Add or Edit Connection, enable Require certificate security in the Security section. Choose system trust, a public PEM or DER certificate, or the server’s SHA-256 certificate fingerprint. A mismatch, expired certificate, failed TLS handshake or unsupported protocol blocks the connection, including reconnects. Secure VNC requires a compatible VeNCrypt 0.2 server with an X.509 mode; standard Mac Screen Sharing does not support it. RDP already uses TLS and can also use this stricter certificate check.

Which RDP features are supported?

RDP supports direct TLS/NLA connections with username/password authentication, desktop display, keyboard and pointer input, scrolling and plain-text clipboard exchange. Where the server supports it, GlanceVNC requests a landscape desktop size matching the session area. RDP gateways, Kerberos or Azure sign-in, audio, file or device redirection are not supported. Nearby discovery finds VNC services; add RDP computers manually.

What VNC versions and authentication methods are supported?

GlanceVNC negotiates RFB 3.3, 3.7 and 3.8. It supports no-password servers, standard VNC password authentication and legacy Apple Remote Desktop Mac login when offered. Compatible VeNCrypt 0.2 servers can use certificate-verified TLS with X509None, X509Vnc or X509Plain. Tight framebuffer compression is supported; Tight Security and anonymous TLS are not.

What framebuffer encodings are supported?

The client supports Tight (including JPEG data within Tight), ZRLE, CopyRect, Hextile and Raw. It also supports Zlib, which it advertises for compatible macOS Screen Sharing sessions. H.264, Tight PNG, standalone JPEG, RRE, CoRRE and ZlibHex are not supported.

Saved connections & iCloud

Do saved connections and passwords sync between devices?

Saved connection profiles can sync through your private iCloud database when iCloud is available, including the protocol and optional certificate security settings. Passwords are stored separately in Apple Keychain and can sync through iCloud Keychain when enabled. The Operating System choice, per-connection session preferences, desktop thumbnails and custom backgrounds stay on this device.

Where are What’s New, the privacy policy and licence notices?

Open Settings from Saved Connections, Nearby Connections or the iPad sidebar. What’s New shows a text-based version history, Privacy Policy opens this website and Third-party licences shows the bundled notices without an internet connection.

Troubleshooting & support

Why does my connection time out?

Check that your device can reach the computer over your local network or through your own VPN, that the selected VNC or RDP server is running, and that its host, port, routing and firewall settings are correct. GlanceVNC connects directly to your server and does not provide a remote-access relay.

Why does authentication fail?

Check the selected protocol and saved credentials. For RDP, use the remote account username and password. For VNC, check the sign-in method. Some Macs offer newer Apple Screen Sharing authentication methods that GlanceVNC does not support; configure a VNC password. For strict VNC security, the server must support VeNCrypt 0.2 with an X.509 mode and the configured certificate or fingerprint must match.

What happens while connecting or if a connection fails?

While connecting, GlanceVNC shows a spinner and the current stage. In version 1.3, Mac Screen Sharing waits up to 30 seconds for the initial desktop dimensions and automatically retries once if desktop preparation times out. RDP graphics setup is more reliable, and the app explains when no desktop image arrives within 15 seconds. If the connection fails, the panel explains why and offers Reconnect. Use the close button to return to your saved connections. You can select the error message to copy it into a support request.

How do I report a support issue?

Email support@glancevnc.com with your device model, iOS or iPadOS version, app version, connection protocol, server type, port, sign-in method and error text. Include the error message from a failed connection, after checking it for private host names or addresses. Do not send passwords.
