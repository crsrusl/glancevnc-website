What’s New

Release notes for GlanceVNC on iPhone and iPad, from the first version to the latest update.

1.8

13 November 2026

  • SSH tunnelling. Connect to VNC and RDP desktops through an SSH gateway. Generate Ed25519 keys, import existing keys and review trusted SSH servers in Settings. Newly generated and imported private keys stay on your device.
  • Widgets, Shortcuts and Siri. Open saved connections from your Home Screen, run the Connect to Computer action in Shortcuts or ask Siri.
  • Customisable session toolbar. Choose which commands appear and put them in the order you want.
  • App lock. Turn on Require authentication in Settings to unlock GlanceVNC with Face ID, Touch ID or your device passcode.
  • iCloud sync controls. Manage sync under Settings → iCloud sync. Sync is on by default and respects your existing choice if you’ve turned it off.

1.7

5 November 2026

A redesigned home screen opens to Saved Connections, with tabs on iPhone and a sidebar on iPad. Connection cards show desktop thumbnails when available, and nearby VNC computers can be opened before saving. Settings and connection forms are simpler, and the selected operating system sets the remote keyboard shortcuts. Apple Pencil supports clicking, dragging and hover on compatible iPads. Clipboard notices clear after five seconds. Compatible VeNCrypt servers can use certificate-verified TLS, and RDP also supports strict certificate verification.

1.6

In-app version history

Added per-connection input and display preferences, optional strict certificate checks for RDP and compatible VNC servers, and more VNC keyboard shortcuts. Command-V sends and pastes device clipboard text, while Command-Shift-V pastes from the remote clipboard. Trackpad input reaches the desktop edges in Fill screen mode. The unused Remote Machine Profile setting was removed.

1.5

25 October 2026

Hardware keyboards work as soon as you connect, and the on-screen keyboard button hides while one is attached. The zoomed view follows the trackpad pointer. Compatible servers can resize the desktop to match the landscape session area. Fill screen crops without stretching, and Fit whole desktop shows the full image. Mac Screen Sharing keeps the Mac’s display resolution.

1.4

4 October 2026

Trackpad mode zooms around the pointer and follows it as it moves. Touch mode zooms around the area you pinch, so you can tap directly on it. Switching modes preserves zoom, and two-finger swipes still scroll the remote desktop.

1.3

28 September 2026

Added plain-text clipboard controls for VNC, Mac Screen Sharing and RDP. Fixed desktop loading for TigerVNC and Mac Screen Sharing. Mac Screen Sharing waits longer for the desktop and retries once if preparation times out. Settings gained a version history.

1.2

25 September 2026

Added support for iOS and iPadOS 18 and later, with Liquid Glass on iOS 26 and later. Improved landscape and larger-text layouts, fixed stretched desktops after rotation and resolved a graphics compatibility crash.

1.1

24 September 2026

Added RDP for compatible Windows and Linux computers, with in-app certificate review and a new prompt if the certificate changes. Improved VNC colour compatibility and RDP graphics startup. Tapping the desktop dismisses the keyboard and still sends the remote click. iCloud sync gained protocol and security details, and Settings gained What’s New, licence notices and privacy links.

1.0

23 September 2026

First release, with VNC and compatible Mac Screen Sharing, saved connections, local VNC discovery, and Touch and Trackpad controls.
