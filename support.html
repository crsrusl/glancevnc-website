GlanceVNC Support

Which devices can run GlanceVNC?

GlanceVNC requires iOS 27 or later on iPhone, or iPadOS 27 or later on iPad. Your remote computer must run a compatible VNC or RDP server that your device can reach.

How do I add a VNC connection?

Tap Add on the home screen, choose VNC under Protocol, enter the host or IP address, confirm the port, choose a sign-in method, and save. Port 5900 is the common VNC default. Addresses can include a vnc:// prefix. Choose the Remote Machine profile that matches your computer, or Unknown for general compatibility defaults.

How do I add an RDP connection?

Tap Add on the home screen, choose RDP under Protocol, enter the host or IP address and port (3389 by default), and save the remote account username and password. Choose the matching Remote Machine profile. Compatible Windows and Linux desktops must have an RDP server enabled and reachable from your device. Ordinary usernames, user@domain names and DOMAIN\username are supported.

How do RDP certificate approvals work?

Certificates are checked when you connect. If approval is needed, review the server certificate in the app and trust it only after verifying it belongs to your computer. Approval is remembered for future connections; a changed certificate requires a new review. To reset approval, edit the saved RDP connection, choose Forget Trusted Certificate and save.

Which RDP features are supported?

RDP supports direct connections with TLS and NLA username/password authentication, desktop display, keyboard input, pointer control and scrolling. RDP gateways, Kerberos or Azure sign-in, clipboard sharing, audio, file or device redirection and controls to request a new remote resolution are not supported. Nearby discovery finds VNC services; add RDP computers manually.

What does Shared or Exclusive mean?

For VNC connections, Shared asks the server to keep other clients connected. Exclusive asks it to disconnect other clients when your session starts. The server decides how to handle the request.

How does nearby discovery work?

GlanceVNC finds Bonjour VNC services advertised as _rfb._tcp. on your local network. Choose a discovered desktop to create a saved connection. Allow Local Network access when prompted. If discovery is unavailable, check the app’s Local Network permission in system Settings, or enter the host and port manually.

Do saved connections and passwords sync between devices?

Saved profiles can sync through your private iCloud database when iCloud is available, including the connection protocol, approved RDP certificate fingerprint, remote computer profile and VNC sharing preference. Passwords are stored separately in Apple Keychain and can sync through iCloud Keychain when enabled. Desktop thumbnails and custom backgrounds are stored locally and are not part of CloudKit profile sync.

What sign-in method should I choose?

For VNC, use Automatic for most servers. With a saved username and password, it can select compatible legacy Mac login when offered; otherwise it can use standard VNC password authentication. Choose VNC password for the password configured for VNC viewers. Choose Mac login only when the server offers legacy Apple Remote Desktop authentication, and supply both the Mac username and password.

How do I connect to a Mac?

Enable Screen Sharing on the Mac and the option allowing VNC viewers to control the screen with a password. In GlanceVNC, add the Mac host name or IP address, choose the macOS Remote Machine profile, select VNC password, and enter that VNC password. A Mac account password is not interchangeable with the separately configured VNC password.

Why does my connection time out?

Check that your device can reach the computer over your local network or VPN, that the selected VNC or RDP server is running, and that its host, port, routing and firewall settings are correct. GlanceVNC connects directly to your server and does not provide a remote-access relay.

Why does authentication fail?

Check the selected protocol and saved credentials. For RDP, use the remote account username and password. For VNC, also check the selected sign-in method. Some Macs offer newer Apple Screen Sharing authentication methods that GlanceVNC does not support; configure a VNC password and select VNC password in the saved connection. Servers requiring Tight Security or VeNCrypt authentication are not supported.

How do I choose Touch or Trackpad mode?

During a connection, tap the upward chevron to show the session controls, open Settings, and choose Touch or Trackpad under Control mode. The change takes effect in the current session. Touch positions the pointer where you touch; Trackpad moves it relative to your finger movement. To set the default for future connections, open home-screen Settings and choose Cursor mode.

What touch gestures are available?

With the default gesture settings, tap for a left click, double-tap for a double-click, use a two-finger tap for a right click, hold and drag to move items, use two fingers to scroll, and pinch to zoom the local view. Pinch zoom changes your view of the desktop, not the computer’s screen resolution. For gesture instructions during a session, open the session Settings menu and select How to control your computer.

How do I send keyboard input?

Tap the keyboard button during a session to show the on-screen keyboard. You can type text and send Enter and Backspace. Use the keyboard dismissal button, or tap the desktop to hide the keyboard in Touch or Trackpad mode. The desktop tap still performs its usual remote click; use the keyboard button to reopen it. The current app does not have a toolbar for function keys, modifier shortcuts or clipboard commands.

How do I choose colour depth?

For VNC connections, open home-screen Settings and choose 16-bit or 24-bit under Colour depth. 16-bit is the default and uses less bandwidth; 24-bit provides richer colour. Both use compression and apply to your next connection.

Can I customise the home screen?

In home-screen Settings, select Choose Background to pick a photo. GlanceVNC stores a resized copy locally. Select Use Default Background to remove it and restore the default appearance. Saved connections can also display locally cached desktop thumbnail previews.

How do I close a remote session?

Tap the upward chevron to show the session controls, open Settings, and choose Close Connection. Confirm when prompted.

What VNC versions and authentication methods are supported?

GlanceVNC negotiates RFB 3.3, 3.7 and 3.8. It supports no-password servers, standard VNC password authentication and legacy Apple Remote Desktop Mac login when offered. Tight framebuffer compression is supported; Tight Security and VeNCrypt authentication are not.

What framebuffer encodings are supported?

The client supports Tight (including JPEG data within Tight), ZRLE, CopyRect, Hextile and Raw. It also supports Zlib, which it advertises for compatible macOS Screen Sharing sessions. H.264, Tight PNG, standalone JPEG, RRE, CoRRE and ZlibHex are not supported.

Can GlanceVNC resize the remote desktop?

GlanceVNC handles desktop-size updates sent by the server. The current app does not offer controls for requesting a different remote resolution. Use pinch zoom to enlarge the local view.

Does clipboard text work?

For VNC, plain text sent by a compatible server using classic RFB clipboard messages is copied to your device clipboard. Extended Clipboard and rich formats are not supported. RDP clipboard sharing is not supported. The current session controls do not include clipboard send or fetch buttons.

What happens while connecting or if a connection fails?

While connecting, GlanceVNC shows a spinner and the current stage. RDP graphics setup is more reliable, and the app explains when no desktop image arrives within 15 seconds. If the connection fails, the panel explains why and offers Reconnect. Use the close button to return to your saved connections. You can select the error message to copy it into a support request.

Where are What’s New, the privacy policy and licence notices?

Open Settings from the home screen. Under About, What’s New lists the latest improvements, Privacy Policy opens the website and Third-party licences shows the bundled notices without an internet connection. You can also read the privacy policy here.

How do I report a support issue?

Email support@glancevnc.com with your device model, iOS or iPadOS version, app version, connection protocol, server type, port, sign-in method and error text. Include the error message from a failed connection, after checking it for private host names or addresses. Do not send passwords.
